# KOC Reporting System Walkthrough

I have successfully built the static HTML/CSS reporting system with a premium, modern design.

## Features Implemented

### 1. Dashboard (`index.html`)
- **Metrics Grid**: Displays 18+ key metrics including Revenue, Ads Cost, ROI, etc.
- **Visuals**: Uses glassmorphism and gradient effects for a high-end look.
- **Table**: Shows recent performance summary.

### 2. KOC Management (`koc-management.html`)
- **Add KOC Form**: Fields for Name, ID, TikTok Link, Phone, Address.
- **Excel Upload**: A drag-and-drop zone for uploading KOC lists.

### 3. Data Upload (`data-upload.html`)
- **Report Upload**: dedicated interface for uploading daily/weekly reports.
- **History**: Shows previous upload history and status.

### 4. KOC List & Detail (`koc-list.html`, `koc-detail.html`)
- **List View**: Overview table of all KOCs with sorting/pagination controls (visual).
- **Detail View**: Deep dive into a specific KOC's performance with their own specific metrics and history.

## How to View
Open `index.html` in your browser to start exploring the system. The navigation bar on the left works to switch between pages.

## Technologies Used
- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Flexbox, Grid, Glassmorphism effects.
- **FontAwesome**: For icons.
- **Google Fonts (Outfit)**: For modern typography.
